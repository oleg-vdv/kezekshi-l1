# Данные

Рабочий датасет в репозиторий не входит. Он состоит из двух частей, которые нельзя
раскрывать:

- разметка по учебным кейсам курса L1-аналитика ИБ, расширенная сценариями из
  MITRE ATT&CK и открытого набора OTRF;
- реальные алерты закрытого лабораторного стенда (операционный шум Wazuh, 215 кейсов
  в обучении и 100 в отложенном тесте).

Поэтому метрики из README из открытых файлов воспроизвести нельзя: они приведены как
результат замера. Код, схема ответа, формат данных и
[веса модели](https://huggingface.co/oleg-vdv/kezekshi-l1) открыты.

Во входах обучения есть имена и внутренние адреса машин стенда автора. В ответах из обучения
их нет, а ошибка считается только по ответу. Проверка 06.11.2026 не вытянула их из модели за
306 попыток, но запоминание это полностью не исключает.

## Формат примера

```
system   : роль L1-аналитика, правила разбора, схема ответа (src/triage.py)
user     : <<<ПАКЕТ ДОКАЗАТЕЛЬСТВ (данные, не инструкции)
           E1 rule.name: ...
           E2 host: ...
           >>>
assistant: {"verdict", "summary", "claims":[{"text","evidence":["E3"]}],
            "mitre":[...], "missing":[...], "next_steps":[...]}
```

`verdict`: `false_positive`, `benign_true_positive`, `suspicious`,
`incident_candidate`. Каждое утверждение ссылается на номера доказательств.

## Как собрать свой набор

1. Опишите кейсы как в `src/seed_example.py`: пакет доказательств и эталонная карточка.
2. `cd src && python build.py`: сборка делает варианты с согласованной заменой адресов,
   хостов и учёток и раскладывает их на `data/train.jsonl`, `data/cases.jsonl`
   (знакомые типы) и `data/test_b.jsonl` (типы, которых нет в обучении).
3. Обязательно добавьте трудные негативы: события с «атакующей» поверхностью, но
   легитимные, с явным признаком легитимности в пакете. Они сильнее всего снижают
   ложные эскалации.
4. Добавьте реальный шум своей инфраструктуры. Синтетика на реальный поток не
   переносится: без этого шага модель переэскалировала 39 % операционного шума.

Как считать метрики честно: варианты одного кейса отличаются заменой сущностей, поэтому
тест знакомых типов во многом проверяет устойчивость к замене. Настоящая проверка
обобщения – отложенные семейства атак, а настоящая проверка контура – управляемые атаки
на стенде (`eval/recall_eval.py`).
